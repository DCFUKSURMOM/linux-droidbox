Android x86 compatible kernel for the og Xbox.

It should in theory work with Android 4.4 and lower

It has been confirmed to work with 2.3.7 in an Xbox emulator (XEMU).

It has not been tested on hardware yet.

It is not pure 5.6, it has the Android binder driver from 5.0 transplanted in, and a patch to reenable the 32 bit binder IPC
